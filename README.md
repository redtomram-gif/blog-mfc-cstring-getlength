# CString and GetLength

MFC console sample showing how `CString::GetLength` behaves when the string contains an embedded `\0`, and how `Trim` and the copy constructor interact with it. Visual Studio 2008 (vcproj) solution.

Originally published at [CString and GetLength](https://blogs.msdn.microsoft.com/thottams/2009/02/06/cstring-and-getlength/) on the MSDN `thottams` blog.

## Building

```text
Open StringSample\StringSample.sln in Visual Studio and build.
```

## Note

This is archived sample code from a blog post written years ago. It targets the .NET Framework / Visual Studio versions of that era and is kept here for reference.
